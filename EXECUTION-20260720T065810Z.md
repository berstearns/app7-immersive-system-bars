## 4. Size — the honest trade

| artifact | .text | file |
|---|---|---|
| C `.so` (previous phases) | ~12 KB | ~17 KB |
| Rust-backed `.so` (host, `opt-level=z`+LTO) | **161.7 KB** | **442 KB** |

Cause: `no_mangle` roots keep core/alloc panic-formatting paths reachable;
`-Wl,--gc-sections` changes nothing (LTO blob). Known shrink paths, all
deferred: nightly `-Zbuild-std` with `panic_immediate_abort`, or removing
panicking core APIs from domain code. Decision: accept size for type safety;
the 20 KB budget was a C-phase discipline, not a product constraint.
