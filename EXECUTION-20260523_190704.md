## What shipped

1. **`TokenTranslation` data class + `tokenTranslations: List<TokenTranslation>` on `RegionTranslation`** (`TranslationData.kt`); matching `TokenTranslationRecord` and `tokenTranslations` field on the Turso `RegionTranslationRecord` DTO for back-compat.
2. **`TranslatedPagesParser.kt`** (commonMain, kotlinx-serializable) — parses the per-page JSON layout produced by `translations-pipeline-v1`: `{conversations: {<img_id>: [{source_text, meaning_translation, literal_translation, token_translations[]}, …]}}`.
3. **`ImageDataSource.loadTranslatedPagesIfAny()`** — default empty; both `FileImageDataSource` impls (Android Gson + Desktop kotlinx) override to scan `<comicDir>/<chapter>/translated_pages/*.json` for every chapter the manifest knows about.
4. **`TranslationRepository.seedFromComic()`** — default no-op; `AndroidTranslationRepository` and Desktop `InMemoryTranslationRepository` override to add the per-comic entries to their caches.
5. **`LauncherViewModel.switchAsset()` + init block** — call `seedFromComic` both on construct and on switchAsset so initial-comic + comic-switch paths both populate.
6. **`_currentTokenTranslations: StateFlow<List<TokenTranslation>>`** — populated in `loadTokenRegionsForBubble()` from the active `RegionTranslation.tokenTranslations`; cleared on `clearZoomState/clearAsset/switchAsset`.
7. **MainScreen bottom panel** — when a token is single-tapped in zoom view, its `tgt` is shown in a new `Surface` directly below the OCR-text panel (color `0xFF004D5A`, text `0xFFB2EBF2`).
8. **`onZoomLongPressed(nx, ny)`** — new viewmodel handler that invokes the existing `showTranslationOverlay()`. Wired in `MainScreen` as: `onLongPress` in zoom mode → `viewModel.onZoomLongPressed(…)`; outside zoom → existing enter-zoom path. The double-tap-miss → overlay path is preserved as fallback (additive, not replacement).

## Verification gap (next session)

The two scripted scenarios `03-zoom-tap-token-translation.sh` and `04-zoom-longpress-meaning-literal.sh` require the app to be **inside zoom mode on a Chapitre_0194 bubble** before they can verify the new UI. Reaching that state via adb means scripting: login as user9395 → tap "Download" on `chainsawman-fr-hq-tokens-translated` in the catalog → wait → open the chapter → navigate to img_001 → long-press the bubble. Reusing the existing `lib/tap-element.sh + ui-dump.sh + find-element.py` keeps it strict adb-scripts-only. Defer if not needed.
