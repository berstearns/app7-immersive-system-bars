## Lessons / observations

- The `ConversationBox.text` field was already in the data model from a previous feature (`app7-ocr-enriched-bubbles_20260401_132137`), and `FileImageDataSource` already prefers `conversations_ocr.json`. So this feature only needed the DISPLAY surface — no JSON-loading code, no data class changes. Small surface (4 files modified, 1 new component).
- The pane "below me" reshuffled mid-session — `app-dev:1.2` was reclaimed by another Claude instance and `app-dev:1.3` is now the desktop-app pane. Detected via `tmux list-panes -a` + `pane_current_command` check before sending gradle commands.
- PaddleOCR's `batch.py` already writes both `ocr_results.json` (verbose) and `conversations_ocr.json` (app-compatible) in one call — no separate converter needed. The wrapper just copies the right file back.
